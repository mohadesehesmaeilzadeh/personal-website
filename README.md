# Personal Website

A simple personal website built with React.

## About

This project is a personal website created as a React practice project.

It includes a home page, an about page, and a contact page.

## Features

- Home page
- About page
- Contact page
- Contact form
- Thank you message after form submission
- React Router
- React State
- Event Handling
- Responsive Design

## Technologies

- HTML
- CSS
- JavaScript
- React
- React Router
- Git
- GitHub

## Pages

### Home

Introduction and general information.

### About

Information about me and my skills.

### Contact

A contact form where users can enter their name, email, and message.
